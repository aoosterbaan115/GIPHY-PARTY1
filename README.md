# GIPHY Party

A fun web application that allows users to search for GIFs using the GIPHY API and display random results directly on the page.

## Overview

This project demonstrates how to work with third-party APIs, asynchronous JavaScript, DOM manipulation, and event listeners. Users can search for a keyword, and the application will retrieve GIFs from GIPHY and display a randomly selected result.

## Features

* Search for GIFs using any keyword
* Fetch data from the GIPHY API using Axios
* Randomly select a GIF from the search results
* Display multiple GIFs on the page
* Remove all displayed GIFs with one click
* Dynamic updates without refreshing the page

## Technologies Used

* HTML
* CSS
* JavaScript
* Axios
* GIPHY API

## How It Works

1. The user enters a search term.
2. A request is sent to the GIPHY API.
3. The API returns an array of matching GIFs.
4. JavaScript randomly selects one GIF from the results.
5. The GIF is added to the page.
6. Users can continue searching to add more GIFs.
7. Clicking the "Remove Images" button clears all displayed GIFs.
